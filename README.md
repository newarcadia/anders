# Anders

Halo Wars tools for Blender, developed by **New Arcadia**.

Import, edit and export models, materials, textures, animations, visual definitions and damage data for Halo Wars: Definitive Edition and Halo Wars 2. Requires Blender 4.2 or newer. Game files are not included.

## Install

In Blender, open **Preferences > Get Extensions > Repositories** and add:

```text
https://github.com/newarcadia/anders/releases/latest/download/index.json
```

Synchronize and install **Anders: Halo Wars Tools**. For manual installation, download the extension ZIP from the [latest GitHub release](https://github.com/newarcadia/anders/releases/latest) and choose **Install from Disk**.
